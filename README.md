# Рекламные макеты «Выбор клиента»

Этот отдельный публичный репозиторий предназначен только для опубликованных рекламных изображений программы повышения качества в сфере детских и семейных услуг «Выбор клиента».

Он не связан с кодом сайта «Кострома Детская» или сервером Beget. Здесь не должны храниться токены, персональные данные, настройки рекламы или конфигурация подключения.

Для ссылок на утверждённые изображения используйте файлы в папке `assets/`.
